Einstellungen

Supabase (Cloud-Speicher)

Projekt auf supabase.com anlegen, das SQL aus supabase/schema.sql im SQL-Editor ausfuehren, dann URL & anon key unter Project Settings → API kopieren.

Claude (Bildschirm-Analyse)

API-Key erstellen unter console.anthropic.com.

Tastenkuerzel

Electron-Accelerator-Syntax, z.B. CommandOrControl+Shift+T. Loest von ueberall auf dem PC eine Bildschirm-Erfassung aus.

macOS: Fuer die Bildschirm-Erfassung muss der App unter Systemeinstellungen → Datenschutz & Sicherheit → Bildschirmaufnahme Zugriff erlaubt werden.
